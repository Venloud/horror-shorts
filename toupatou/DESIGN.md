# Toupatou design brief
Audience: independent video creators managing distribution without an agency.
Single job: help a creator understand and preview one-video-to-many-channel publishing.
Feel: kinetic, human, precise.
Signature moment: interactive publish board routes one real-looking vertical clip into selected channel lanes.
Palette: ink #17222A, paper #E9E3D8, cobalt #355BDA, papaya #FF6A43, chalk #F7F4ED.
Type pair: system UI sans for all functional text; Georgia italic reserved for selected editorial moments.

## Design rules
The app *is* the hero. Show the publishing desk immediately, not generic marketing slogans or feature cards.
Haitian influence comes from language, sound and color rhythm, not stereotyped flags or pasted decorative patterns.
Hierarchy: show action, context, evidence. Don't use tracking-heavy eyebrows or decorative numbered sections.
Never show a publishing success unless the actual API confirms it. The demo is labeled interactive preview.
Desktop and mobile must both preserve explicit controls and accessible readable text.
Respect reduced motion. No autoplay motion that conveys essential state.
Platform marks are illustrative text, not impersonation of an official integration.
