# Ruflo Task Contract: Visual Planner

## Purpose
Translate approved narration and story-bible information into specific visual shots.

## Inputs
- Approved narration
- Story bible
- Shot rules
- Character/location continuity requirements

## Outputs
- Shot sequence
- Visual intent per shot
- Character/location continuity notes
- Image or media prompt guidance

## Responsibilities
- Keep visuals synchronized with narration.
- Use the canonical story-bible character and location details.
- Make each shot specific and narratively useful.
- Preserve existing image QA and child-shot sanitization rules.
- Respect the Night Files prohibition on occult/illuminati imagery.

## Constraints
- Never use generic filler when a specific narrative visual is possible.
- Never change locked character details without an explicit upstream change.
- Never bypass visual QA.
- Never introduce prohibited occult symbols or imagery.
