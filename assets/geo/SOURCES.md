# Offline geo pack

- countries.json: Natural Earth 1:50m Admin 0 (public domain), simplified 0.04 deg.
- admin1.json: Natural Earth 1:10m Admin 1 states / provinces (public domain), simplified 0.02 deg.
- cities.json: Natural Earth 1:10m populated places, scalerank <= 8 (public domain).
- flags/*.png: rendered from the Noto Color Emoji font (SIL OFL 1.1 font; Apache-2.0 images).
Built by tools/build_geo_pack.py; https://www.naturalearthdata.com/about/terms-of-use/
