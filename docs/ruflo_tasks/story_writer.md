# Ruflo Task Contract: Story Writer

## Purpose
Create or revise Night Files narration using research that has already been gathered.

## Inputs
- Research findings and sources
- Fact lock
- Story mode
- Existing Night Files duration target
- Existing hook and safety rules

## Outputs
- Draft narration
- Hook
- Story structure
- Fact-lock notes
- Any claims requiring additional verification

## Responsibilities
- Open with the strongest concrete hook.
- Preserve verified facts and source boundaries.
- Match the existing Night Files narration duration target.
- Keep fiction explicitly separated from true stories and folklore.
- Preserve the channel's Christian imagery restriction.

## Constraints
- Never invent factual details to improve drama.
- Never copy another creator's script.
- Never weaken fact-lock or quality gates.
- Never change publishing behavior.
