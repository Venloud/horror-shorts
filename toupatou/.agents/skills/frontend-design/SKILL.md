## Toupatou application
Define subject-specific layout first; reject default SaaS hero + three cards patterns. Use the publishing workspace itself as the distinctive first impression. Establish and critique a token system before coding. Prefer purposeful, user-triggered motion over decorative loops. Favor meaningful content over filler and treat empty/error states as core design.
