# Toupatou, publishing desk preview

This folder contains the product-first Toupatou design and its supporting skills.

- [preview.html](preview.html): self-contained, responsive interactive publishing desk, no dependencies, no backend.
- [DESIGN.md](DESIGN.md): product-centered design tokens, UX concept and guiding rules.
- [frontend-design skill](.agents/skills/frontend-design/SKILL.md): upstream Anthropic skill link and Toupatou application notes.
- [web-design-guidelines skill](.agents/skills/web-design-guidelines/SKILL.md): upstream Vercel accessibility and UI audit instructions.
- [premium-motion skill](.agents/skills/premium-motion-website/SKILL.md): adaptation of owner-provided motion stack instructions.

## Preview

Download or open `preview.html` locally in a browser. Click the destination switches, edit the caption, and press **Preview publishing plan**. No real social account is accessed.

## Scope

Not deployed. Not a functional posting service. TikTok OAuth, production approval, scheduling, hosted backend and platform integrations are future tasks. Preview interactions are local only. No Night Files workflows are changed by this update.
