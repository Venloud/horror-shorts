# Ruflo Task Contract: Researcher

## Purpose
Research a selected Night Files topic and return source-backed material for the existing story system.

## Inputs
- Selected topic or search query
- Existing Night Files topic metadata
- Existing source/research requirements

## Outputs
- Verified factual findings
- Source URLs/titles
- Fact versus folklore/speculation distinctions
- Important uncertainty or disputed claims

## Responsibilities
- Search the exact topic first.
- Prefer primary sources, government records, museums, academic sources, and reputable historical references.
- Preserve traceability for every important factual claim.
- Identify whether the topic is true, folklore, disputed, or fictional.
- Return evidence to the existing research/story process rather than publishing directly.

## Constraints
- Never invent facts or citations.
- Never turn folklore into established fact.
- Never declare a story true without sufficient evidence.
- Never publish or modify platform state.
