# Night Files high-resolution closeup set

This is a **standalone optional pack** of sharp, native-vector 1600 × 2000 close-up PNGs for the black-suit/red-tie white-head host. All PNG files have true RGBA transparency and no ground/shadow. A separate editable SVG is included for every PNG, allowing lossless rerendering at higher resolutions. The SVGs are original redraws guided by the approved character sheet; they are **not exact AI art from that sheet**. Review the artwork before replacing any established poses.

There are no GitHub commits, branches, workflows, or changes to the existing 102-character library. To test, extract only into `assets/character/host/closeups/` **within Claude's current development branch**, and teach the sprite selector to use these files specifically for close-up framing. Do not overwrite full-body poses. The full-body character feet align bottom-center, but these close-ups crop naturally at the bottom and cannot be used as full-body walking/standing cycles.

Use the visual contact sheet in this archive as a preview, not as a rendering asset. Face close-up selection can key by `(view, expression)`. Preserve TikTok draft mode and the existing classic fallback.
