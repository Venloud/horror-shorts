# Ruflo Task Contract: Packaging Reviewer

## Purpose
Review platform-facing metadata before the existing publisher handles transport.

## Inputs
- Final story
- Existing caption
- Title
- Hashtags
- Pinned comment
- YouTube metadata
- Platform-specific limits

## Outputs
- Metadata review
- Suggested title/caption/hashtag changes
- Platform compliance warnings
- Final metadata recommendations

## Responsibilities
- Check that packaging accurately represents the story.
- Preserve true-story, folklore, and fiction labeling.
- Keep metadata within existing platform constraints.
- Review TikTok and YouTube metadata independently.
- Leave actual upload/authentication to the existing publisher.

## Constraints
- Never publish directly.
- Never change TikTok OAuth behavior.
- Never remove required fiction or factual-status labeling.
- Never make unsupported factual claims in metadata.
