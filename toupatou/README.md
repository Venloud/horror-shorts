# Toupatou website

Standalone brand preview for Toupatou, a Haitian Creole-inspired content publishing platform.

## Preview

Open `preview.html` in any browser, no dependencies required. The file is self-contained and does not alter Night Files publishing workflows.

## Development

This is a marketing preview, not an authorized TikTok publishing interface. OAuth, account connections, and scheduling remain future work, subject to TikTok production review.

The original Vite + Three.js + GSAP + Lenis development ZIP is available in the ChatGPT conversation artifact, and is not represented by this dependency-free preview file.
